    How to Re-seed

    To clear and re-seed the database:

    cd app
npm run prisma:seed

    This will: 1. Clear existing items and tags 2. Create 53 new items with comprehensive attributes 3. Display a summary by category and sub-type

    Verification Commands

    # Check database status
npm run db:check

# Open Prisma Studio to browse data
npm run prisma:studio

# Query item count via SQL
